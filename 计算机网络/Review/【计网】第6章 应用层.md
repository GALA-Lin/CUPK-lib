应用层是计算机网络体系结构的最顶层，主要关注特定应用进程之间通信的细节。本章的**核心考点**集中在各个协议的**工作原理**、**使用的传输层协议**及**端口号**。

### 第六章：应用层 复习重点

#### 1. 应用层协议概述
* **地位：** 应用层直接为用户应用进程提供服务。
* **特点：** 应用层的许多协议都是基于 **客户-服务器 (Client-Server)** 方式。
    * **客户 (Client)：** 服务请求方，主动发起通信。
    * **服务器 (Server)：** 服务提供方，被动等待连接请求。

#### 2. 域名系统 DNS (Domain Name System) [必考]
* **用途：** 将用户友好的**域名**解析成网络使用的 **IP 地址**。
* **使用的协议和端口：** 主要使用 **UDP 53** 端口，但域名信息过多时会使用 **TCP 53** 端口。
* **域名结构：** 层次结构，由点分隔。
    * 根域名服务器 ($\cdot$) $\to$ 顶级域名 (如 .com, .cn) $\to$ 二级域名 $\to$ 三级域名...。
* **域名服务器类型：**
    * **根域名服务器：** 全球只有 13 套，知道所有顶级域名服务器的地址。
    * **顶级域名服务器 (TLD)：** 负责该顶级域名下所有二级域名服务器的地址。
    * **权限域名服务器 (Authoritative)：** 负责一个区，存储该区内的所有主机信息。
    * **本地域名服务器：** 客户机首先查询的对象，**不属于** DNS 的层次结构。
* **域名解析方式 [对比记忆]：**
    * **递归查询 (Recursive Query)：** 客户只向本地域名服务器查询，本地域名服务器代为完成所有后续查询。
    * **迭代查询 (Iterative Query)：** 本地域名服务器向其他域名服务器查询时，后者只返回下一级域名服务器的地址，不代为查询。

#### 3. 万维网 WWW (World Wide Web)
* **核心概念：**
    * **URL (统一资源定位符)：** 用于标识万维网上的资源位置，格式为 `协议://主机:端口/路径`。
    * **HTML (超文本标记语言)：** 描述页面的语言。
* **超文本传送协议 HTTP (HyperText Transfer Protocol) [重点]：**
    * **用途：** 从万维网服务器传输超文本到本地浏览器。
    * **使用的协议和端口：** **TCP 80** 端口。
    * **连接方式 [对比记忆]：**
        * **非持久连接 (Non-Persistent)：** 每传输一个对象（如 HTML 文件、图片）就**建立一个 TCP 连接**，传输完成后立即释放。
        * **持久连接 (Persistent)：** 建立一个 TCP 连接后，服务器在发送响应后**不关闭连接**，可用于后续多个对象传输。
    * **工作过程：** 客户建立 TCP 连接 $\to$ 客户发送 HTTP 请求报文 $\to$ 服务器发送 HTTP 响应报文 $\to$ 释放 TCP 连接。
    * **Cookie：** 用于记录用户身份、购物信息等，是服务器用来跟踪用户状态的技术。

#### 4. 电子邮件系统 [重点]
* **组成部分：** 用户代理（客户端）、邮件服务器、协议。
* **核心协议：**
    1.  **SMTP (简单邮件传送协议)**
        * **用途：** 客户机 **推送** 邮件给服务器，或服务器之间 **传输** 邮件。
        * **使用的协议和端口：** **TCP 25**。
        * **特点：** 基于 **ASCII 文本**，不能传输可执行文件或其他非文本数据。
    2.  **MIME (通用因特网邮件扩充)**
        * **用途：** 解决 SMTP 只能传输 ASCII 文本的限制，使邮件能支持多种数据类型（如图像、音频、中文等）。
    3.  **POP3 (邮局协议版本 3)**
        * **用途：** 用户代理从邮件服务器 **拉取/读取** 邮件。
        * **使用的协议和端口：** **TCP 110**。
        * **模式：** 两种模式——**下载并删除**（默认）、**下载并保留**。
    4.  **IMAP (因特网邮件访问协议)**
        * **用途：** 更先进的邮件读取协议，允许用户在服务器上管理邮件，如创建文件夹、查找邮件。
        * **使用的协议和端口：** **TCP 143**。

#### 5. 动态主机配置协议 DHCP (回顾)
* **用途：** 终端主机自动获取 IP 地址、子网掩码、网关等配置信息。
* **使用的协议和端口：** **UDP**。服务器使用 **67** 端口，客户使用 **68** 端口。
* **工作流程（四报文发现过程）[必考]：**
    1.  **DHCPDISCOVER** (发现)：客户 $\to$ 服务器（广播）。
    2.  **DHCPOFFER** (提供)：服务器 $\to$ 客户（单播/广播）。
    3.  **DHCPREQUEST** (请求)：客户 $\to$ 服务器（广播）。
    4.  **DHCPACK** (确认)：服务器 $\to$ 客户（单播/广播）。
