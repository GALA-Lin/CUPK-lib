# 分组交换的要点

分组交换的要点可分以下几点详细说明：
 ## **核心技术：存储转发**

   分组交换最突出的特点是采用**存储转发技术**，数据不是在网络中直接连续传输，而是以“存储 - 转发”的模式逐段传递。
 ## **分组的创建过程**

   - 定义“报文”：要发送的整块数据被称为**报文**。
   - 划分“数据段”：发送报文前，将较长的报文划分成**更小的等长数据段**（例如，每个数据段可设为1024 bit）。
   - 构建“分组”：给每个数据段添加**首部**（包含目的地址、源地址等关键控制信息，首部也被称为“包头”），由此构成**分组**（又称“包”）。分组是互联网中传送的基本数据单元，其首部的控制信息让每个分组能在互联网中**独立选择传输路径**。
 ## **路由器的分组转发操作**

   - 网络核心角色：互联网的核心由众多网络和互连它们的**路由器**组成，路由器是分组交换的“执行者”。
   - 接收与存储：路由器收到一个分组后，会先**临时存储**（存储时间极短）。
   - 检查与查找：接着检查分组的**首部**，依据首部中的目的地址，**查找路由器内部的转发表**。
   - 转发传递：按照转发表找到合适的输出接口，将分组**转发**给下一个路由器。通过这样“逐跳式”的存储转发，分组最终能被交付到最终的目的主机。
 ## **路由信息的交换与转发表维护**

   各路由器之间需要**频繁交换路由信息**，目的是**创建并维护路由器中的转发表**。当整个网络的拓扑结构发生变化时，转发表能通过路由信息的更新及时调整，从而保证分组转发的准确性和效率。

# 【1-03】试从多个方面比较电路交换、报文交换和分组交换的主要优缺点。

| **特点**     | **电路交换 (Circuit Switching)**                   | **报文交换 (Message Switching)** | **分组交换 (Packet Switching)**                      |
| ------------ | -------------------------------------------------- | -------------------------------- | ---------------------------------------------------- |
| **原理**     | 建立连接 $\rightarrow$ 通话 $\rightarrow$ 释放连接 | 整个报文存储转发（已很少使用     | 采用 **存储转发** 技术，将数据切分成固定长度的“分组” |
| **资源占用** | 通话期间始终占用端到端资源 (独占)                  | 逐段占用                         | 逐段占用链路，动态分配带宽                           |
| **优点**     | 传输大量连续数据时效率高，时延小                   | 不需要预分配带宽                 | **高效、灵活、迅速、可靠**                           |
| **缺点**     | 线路利用率低，建立连接需时间                       | 时延较长，对缓存要求高           | 排队造成时延，首部造成开销                           |

要从**连接建立、资源利用、时延特性、可靠性、适用场景**等方面，对比电路交换、报文交换和分组交换的优缺点：


### 一、电路交换
#### 优点
- **实时性强**：通信建立连接后，数据直接、连续传输，**传输时延小**，适合**语音、视频等实时性要求高的业务**（如传统固定电话通信）。
- **通信透明性好**：通信双方**独占物理信道**，传输过程不受其他数据干扰，传输质量稳定。

#### 缺点
- **资源利用率低**：通信全程独占信道，即使无数据传输（如通话间隙）也不释放资源，对**突发性数据（如计算机数据）**的资源浪费严重。
- **连接建立时间长**：通信需经历“**建立连接→通信→释放连接**”三个阶段，若某段链路无空闲资源，连接无法建立，灵活性差。
- **可靠性差**：连接建立后路径固定，若链路、交换机等环节故障，**整个通信会中断**。


### 二、报文交换
#### 优点
- **无需预先建立连接**：采用“**存储 - 转发**”方式，报文到达节点后先存储，再根据网络状态选路转发，**资源共享性好**，信道利用率高。
- **可靠性较高**：某节点或链路故障时，报文可通过其他路径转发，网络抗故障能力强。
- **支持异构通信**：能适配**不同速率、不同协议的设备**之间的通信（如早期电报系统）。

#### 缺点
- **传输时延大**：需存储**整个报文**后再转发，报文越长，存储、转发的时延越显著，**不适合实时通信**（如语音、视频）。
- **缓存需求大**：每个节点需为每个报文分配足够缓存空间，若报文长度差异大，缓存管理复杂。
- **应用场景受限**：曾用于电报，因实时性差，现在已很少使用。


### 三、分组交换
#### 优点
- **资源利用率高**：继承报文交换“存储 - 转发”与资源共享的特点，且将报文分割为**小分组**，多个分组可**动态共享链路带宽**，特别适合**突发性数据传输**（如计算机网络数据）。
- **传输时延较报文交换小**：分组长度固定且较短，节点存储、转发的时间更短，实时性优于报文交换。
- **可靠性强**：每个分组**独立选路**，某链路故障时，分组可通过其他路径到达目的，网络“生存性”好（如互联网能自适应故障）。
- **灵活性好**：便于不同类型业务（数据、语音、视频）共享网络；且分组体积小，对节点缓存空间的要求低于报文交换。

#### 缺点
- **存在额外开销**：每个分组需携带**首部（控制信息）**，增加了数据传输的额外开销。
- **有排队时延**：分组在路由器中存储转发时需排队，**网络拥塞时排队时延会增大**，甚至导致分组丢失（需依赖拥塞控制协议解决）。
- **重组开销**：分组到达目的主机后，需将多个分组**重组为原始报文**，增加了接收端的处理开销。


### 总结
- 电路交换适合**长时、实时的连续通信**（如传统电话）；
- 报文交换因实时性差，应用场景已基本被取代；
- 分组交换是**计算机网络的核心交换方式**，适合互联网的**异构、突发性数据传输**场景，是目前应用最广泛的交换技术。

# 【1-12】互联网的两大组成部分（边缘部分与核心部分）的特点是什么？它们的工作方式各有什么特点？

互联网的两大组成部分（边缘部分与核心部分）的特点及工作方式如下：


### 一、边缘部分
#### 组成特点
由**所有连接在互联网上的主机**组成，是用户直接使用的部分，用于实现**通信（传输数据、音频、视频等）**和**资源共享**。

#### 工作方式特点
网络边缘的端系统（主机）之间的通信方式主要分为两类：
- **客户-服务器（C/S）方式**：客户进程作为**服务请求方**，主动向作为**服务提供方**的服务器进程发起请求（例如Web浏览时，浏览器是“客户”，Web服务器提供网页服务）。
- **对等（P2P）方式**：通信的端系统**地位平等**，彼此既可以作为“服务请求方”，也可以作为“服务提供方”（例如部分文件共享、即时通信应用）。


### 二、核心部分
#### 组成特点
由大量**网络（如局域网、广域网等）**和连接这些网络的**路由器**组成，为边缘部分提供**连通性**和**交换服务**（支撑边缘部分的主机通信）。

#### 工作方式特点
核心部分的工作依赖两种关键行为：
- **路由器转发分组**：路由器是实现分组交换的关键构件，其任务是接收、临时存储分组，再通过查找**路由表**，将分组转发到下一个路由器，以“存储-转发”的方式为主机间的通信传递数据。
- **路由器之间交换路由信息**：各路由器需遵循**路由选择协议**，相互交换路由信息，使路由表能及时反映**网络拓扑的变化**（如链路故障、新网络加入），确保分组转发的准确性。

# 计算机网络常用的性能指标

1. **速率**：主机在数字信道上传输数据的速度，也叫“数据率”或“比特率”，比如每秒能传多少比特（bit）的数据。
2. **带宽**：网络通信线路传送数据的能力，指单位时间内（通常是每秒）从网络某一点到另一点能通过的“最高数据率”，类似道路的“最大通行能力”。
3. **吞吐量**：单位时间内（通常是每秒）实际通过某个网络、信道或接口的数据量，体现实际的“数据传输量”。
4. **时延**：数据（比如一个报文、分组）从网络（或链路）一端传到另一端所需的时间。它包含**发送时延**（发送数据的时间）、**传播时延**（信号在介质里传播的时间）、**处理时延**（设备处理数据的时间）、**排队时延**（排队等待转发的时间）。
5. **时延带宽积**：传播时延（单位：秒）和带宽（单位：bit/s）的乘积，能反映链路中大约“存储”了多少比特的数据，也被称为“以比特为单位的链路长度”。
6. **往返时间**：从发送方发数据开始，到发送方收到接收方的确认（接收方收到数据后立即发确认）的总时间。有时还包含网络中间节点的处理、排队、转发等时延。
7. **利用率**：分“信道利用率”和“网络利用率”。信道利用率是某信道有数据通过的时间比例（完全空闲时利用率为0）；网络利用率是全网络信道利用率的加权平均值，体现网络整体被使用的程度。

### 【2-01】物理层要解决哪些问题？物理层的主要特点是什么？
- 要解决的问题：在不同传输媒体上**透明传输比特流**，比如规定“1”“0”的电信号表示、电缆插头引脚连接方式等，屏蔽各类传输媒体和硬件的差异，让上层（数据链路层）无需关注底层传输细节。
- 主要特点：传输数据的单位是**比特**；任务是“透明”传送比特流（发送“1”接收方必收“1”，而非“0”）；不涉及比特的含义，传输媒体（如双绞线、光缆等）不属于物理层协议内容。


### 【2-04】解释以下名词
- **数据**：传递消息的实体；**信号**：数据的电气/电磁表现形式。
- **模拟数据/信号**：数据/信号的参数**连续变化**（如语音声波是模拟数据，电话话筒输出的电信号是模拟信号）。
- **基带信号**：信源直接产生的“基本频带”信号（如计算机输出的文字数据信号）；**带通信号**：基带信号经载波调制、搬移到高频段的信号（适合信道传输）。
- **数字数据/信号**：数据/信号的参数**离散变化**（如键盘输入是数字数据，计算机内部的电信号常为数字信号）。
- **码元**：信号编码的基本单元，简单二进制编码时，1个码元对应1个比特；复杂编码时，1个码元可包含多个比特。
- **通信方式**：单工（单向传，如广播）、半双工（双向交替传，不能同时发收）、全双工（双向同时传）。
- **传输方式**：串行（比特逐次传输）、并行（多信道同时传多个比特）。


### 【2-06】数据在信道中的传输速率受哪些因素的限制？信噪比能否任意提高？香农公式在数据通信中的意义是什么？“比特／秒”和“码元／秒”有何区别？
- 传输速率限制：①**信道带宽**（信道能通过的频率范围有限，高频分量衰减会导致“码间串扰”，模糊码元边界）；②**噪声**（随机噪声会使码元判决错误，速率越高越易出错）。
- 信噪比不能任意提高：信号传输功率受经济、器件等限制，电子设备的“固有噪声”也无法做到任意小。
- 香农公式意义：只要信息传输速率**低于信道的极限传输速率**，就一定能找到方法实现**无差错传输**（但未给出具体实现方法）。
- “比特/秒”vs“码元/秒”：前者是**数据速率**（每秒传多少比特），后者是**码元速率**（每秒传多少码元）；二进制编码时，两者数值相等；复杂编码时，1个码元可对应多个比特，故数值不同。


### 【2-07】假定某信道受奈氏准则限制的最高码元速率为20000码元／秒。如果采用振幅调制，把码元的振幅划分为16个不同等级来传送，那么可以获得多高的数据率(bit/s)？
已知最高码元速率为20000码元/秒，振幅划分为16个等级（\( 16 = 2^4 \)，即1个码元可表示4个比特）。因此，数据率（比特/秒）= 码元速率 × 每个码元含的比特数 = \( 20000 × 4 = 80000 \, \text{bit/s} \)。


### 【2-17】 试比较ADSL，HFC以及FTTx接入技术的优缺点。
- **ADSL**：
  优点：利用现有电话线，无需重新布线；可按需求选择带宽（按带宽付费）。
  缺点：对用户线质量要求高，若距离电话交换局远或线路噪声大，速率会明显降低。
- **HFC**：
  优点：覆盖面广，带宽高，能传高速数据。
  缺点：需改造原有单向有线电视电缆为双向通信；用户需加机顶盒；电缆中大量放大器会降低网络可靠性。
- **FTTx**：
  优点：数据率极高，通信质量最好，是宽带接入的“理想方案”。
  缺点：大规模部署需大量建设资金。
