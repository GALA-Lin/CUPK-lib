### 第二章：物理层 复习重点

- 数据：运送消息的实体（模拟数据：取值连续；数字数据：取值离散）。
- 信号：数据的电气 / 电磁表现（模拟信号：取值连续；数字信号：取值离散）。
- 码元：数字信号的基本波形，代表不同离散数值的基本单位（1 波特 = 每秒 1 个码元）。
- 信道：向某一方向传送信息的媒体（区别于 “链路”，链路是物理线路段，信道侧重传输方向）。

#### 1. 物理层的基本概念
* **功能：** 屏蔽不同传输媒体和通信手段的差异，让数据链路层感觉不到差异，透明传输比特流。
* **四大特性 (必背)：**
    * **机械特性：** 接口形状、尺寸、引脚数目等 。
    * **电气特性：** 电压范围。
    * **功能特性：** 电平电压的意义 。
    * **过程特性：** 事件的出现顺序。

#### 2. 数据通信基础 [重点]
* **通信方式：**
    * **单工通信：** 单向（如广播）。
    * **半双工通信：** 双向交替，不能同时（如对讲机）。
    * **全双工通信：** 双向同时（如电话）。
* **编码方式 (基带调制)：**
    * **不归零制 (NRZ)：** 简单，但无同步功能，易产生直流分量。
    * **曼彻斯特编码 (Manchester)：** 每一位**中间有跳变**。跳变既是时钟也是数据，**具有自同步能力**。
    * **差分曼彻斯特编码：** 位开始边界有跳变代表0，无跳变代表1。抗干扰更好 。
* **带通调制：** 调幅(AM)、调频(FM)、调相(PM)、正交振幅调制(QAM) [cite: 1535-1540]。

#### 3. 信道的极限容量 [计算题核心]
* **奈氏准则 (Nyquist)：** 理想低通信道，无噪声。
    * 公式：**最高码元传输速率 = 2W (Baud)**。
    * 注意：这里算的是**码元**速率（波特率）。若1个码元携带 $n$ bit 信息，则数据率 = $2W \times n$ (bit/s)。
* **香农公式 (Shannon)：** 带宽受限且有高斯白噪声。
    * 公式：**$C = W \log_2(1+S/N)$** (bit/s) 。
    * **信噪比换算：** 题目通常给分贝 (dB)，需先换算成数值比。
        $$dB = 10 \log_{10}(S/N)$$
        * 例：30dB $\rightarrow$ $S/N = 1000$ 。
    * 结论：信噪比越大，极限传输速率越高。

#### 4. 传输媒体
* **导引型：**
    * **双绞线：** UTP (无屏蔽) 和 STP (屏蔽) 。
    * **同轴电缆：** 50Ω (数字传输) 和 75Ω (模拟/有线电视) 。
    * **光纤：**
        * **多模光纤：** 多条路径，距离近，光源为 LED。
        * **单模光纤：** 单一路径，距离远，衰耗小，光源为激光。
* **非导引型：** 短波、微波 (地面接力/卫星)、Wi-Fi 。

#### 5. 信道复用技术 [重点与难点]
* **频分复用 (FDM)：** 不同用户占用不同频率，同时通信 。
* **时分复用 (TDM)：** 不同用户在不同时间占用同样带宽 。
    * **统计时分复用 (STDM)：** 按需动态分配时隙，利用率高 。
* **波分复用 (WDM)：** 光的频分复用 。
* **码分复用 (CDM/CDMA)：** [必考计算]
    * **原理：** 每个站分配一个唯一的 **码片序列 (Chip Sequence)**。必须互相 **正交** (规格化内积为 0)。
    * **发送：** 发送 1 发原序列，发送 0 发反码序列。
    * **接收 (计算方法)：** 将收到的混合信号与某站的码片序列进行 **规格化内积**。
        * 结果为 1 $\rightarrow$ 发送了 1
        * 结果为 -1 $\rightarrow$ 发送了 0
        * [cite_start]结果为 0 $\rightarrow$ 未发送数据 [cite: 1849-1850]。

#### 6. 宽带接入技术
* **ADSL：** 非对称数字用户线。利用电话线，**上行下行速率不对称** (下行快)，采用 DMT 技术。

* **HFC：** 光纤同轴混合网。基于有线电视网，主干用光纤，入户用同轴电缆，使用 **Cable Modem**。

  **FTTx：** 光纤到户 (FTTH) 等 。

### 特别提醒：针对 PPT 末尾习题的解析
PPT 最后给出了一个 CDMA 的计算题 ，这通常是期末大题的热门考点。

**题目：**
收到序列：`(-1 +1 -3 +1 -1 -3 +1 +1)`
已知码片序列：
A: `(-1 -1 -1 +1 +1 -1 +1 +1)`
B: `(-1 -1 +1 -1 +1 +1 +1 -1)`
C: `(-1 +1 -1 +1 +1 +1 -1 -1)`
D: `(-1 +1 -1 -1 -1 -1 +1 -1)`

**解题思路：**
计算收到的序列与 A, B, C, D 各自的规格化内积 (对应位相乘求和，再除以 8)。

* **A 站：**
    $(-1)\times(-1) + 1\times(-1) + (-3)\times(-1) + 1\times1 + (-1)\times1 + (-3)\times(-1) + 1\times1 + 1\times1$
    $= (1 - 1 + 3 + 1 - 1 + 3 + 1 + 1) / 8 = 8 / 8 = 1$
    **结论：A 站发送了 1**

* **B 站：**
    $(-1)\times(-1) + 1\times(-1) + (-3)\times1 + 1\times(-1) + (-1)\times1 + (-3)\times1 + 1\times1 + 1\times(-1)$
    $= (1 - 1 - 3 - 1 - 1 - 3 + 1 - 1) / 8 = -8 / 8 = -1$
    **结论：B 站发送了 0**

建议你自己算一下 C 和 D，如果结果是 0，则说明没发送数据。这是一份基于你提供的《计算机网络（第8版）谢希仁》第二章 PPT 的期末复习总结。
