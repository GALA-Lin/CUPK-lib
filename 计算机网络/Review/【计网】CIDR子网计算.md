# 子网划分核心公式与常见题型解题步骤（备考专用）
## 一、核心公式（必考！标注适用场景）
| 公式名称               | 公式表达式                                                                  | 适用场景                                | 备注（易错点）                                   |
| ------------------ | ---------------------------------------------------------------------- | ----------------------------------- | ----------------------------------------- |
| 1. 子网数计算           | 子网数 = \(2^n\)（\(n\) = 新增的子网位位数，即原网络位与新网络位的差值）                          | 已知原网络地址（如/24）和新子网掩码（如/27），求划分后的子网总数 | 仅适用于**定长子网划分**（所有子网大小相同）                  |
| 2. 每个子网可用主机数       | 可用主机数 = \(2^h - 2\)（\(h\) = 主机位位数 = 32 - 新网络位总数）                       | 已知子网掩码，求单个子网可分配的主机地址数               | 减2是因为**子网网络地址（全0）和广播地址（全1）不可分配**          |
| 3. 子网掩码转换（十进制→二进制） | 子网掩码十进制 = 前\(k\)位为1，后\(32-k\)位为0（\(k\) = 新网络位总数，如/29对应255.255.255.248） | 将CIDR格式（如/27）转换为点分十进制掩码             | 最后一个字节计算：\(256 - 2^h\)（\(h\)为主机位位数）       |
| 4. 子网网络地址计算        | 子网网络地址 = IP地址 & 子网掩码（二进制按位与运算）                                         | 已知IP地址和子网掩码，求所属子网的网络地址              | 二进制运算更准确，避免十进制计算错误                        |
| 5. 子网广播地址计算        | 广播地址 = 子网网络地址                                                          | （主机位全1的二进制）（按位或运算）                  | 例：子网网络地址192.168.5.0（/29），广播地址为192.168.5.7 |
| 6. 子网地址范围计算        | 可用地址范围 = 子网网络地址 + 1 ~ 广播地址 - 1                                         | 求单个子网可分配的主机地址区间                     | 首尾地址为保留地址，不可分配给主机                         |


## 二、[[【计网】第2章 物理层]]常见题型解题步骤（结合真题案例）
### 题型1：已知网络地址和子网掩码，求子网数、可用主机数（基础题）
#### 解题步骤：
1. 确定原网络位和新网络位：  
   - 原网络位：由IP地址类别或CIDR前缀确定（如A类/8、B类/16、C类/24；192.168.5.0/24原网络位=24）。  
   - 新网络位：子网掩码对应的CIDR前缀（如子网掩码255.255.255.248对应/29，新网络位=29）。  
2. 计算新增子网位\(n\)：\(n = 新网络位 - 原网络位\)（如29-24=5）。  
3. 代入公式求子网数：子网数=\(2^n\) （如\(2^5=32\)个子网）。  
4. 计算主机位\(h\)：\(h=32-新网络位\)（如32-29=3）。  
5. 代入公式求可用主机数：\(2^h - 2\)（如\(2^3-2=6\)）。  

#### 真题案例：
已知网络地址192.168.1.0/24，子网掩码255.255.255.224（/27），求子网数和每个子网的可用主机数。  
解：  
1. 原网络位=24，新网络位=27 → \(n=27-24=3\)。  
2. 子网数=\(2^3=8\)。  
3. 主机位\(h=32-27=5\) → 可用主机数=\(2^5-2=30\)。  
答案：8个子网，每个子网30个可用主机。


### 题型2：已知需求（子网数、每个子网的主机数），求子网掩码（高频题）
#### 解题步骤：
1. 确定原网络位（如C类网络默认/24，B类默认/16）。  
2. 根据所需子网数，计算最小子网位\(n\)：满足\(2^n ≥ 所需子网数\)（取最小的\(n\)）。  
3. 根据每个子网的主机数，计算最小主机位\(h\)：满足\(2^h - 2 ≥ 所需主机数\)（取最小的\(h\)）。  
4. 验证新网络位：新网络位=原网络位+\(n\)，且需满足\(新网络位 + h ≤ 32\)（主机位\(h\)需足够）。  
5. 推导子网掩码：新网络位对应CIDR前缀（如/27），转换为点分十进制（如255.255.255.224）。  

#### 真题案例：
已知网络地址172.16.0.0/16（B类），需划分成30个子网，每个子网至少支持50台主机，求子网掩码。  
解：  
1. 原网络位=16（B类默认）。  
2. 子网数需求：\(2^n ≥30\) → \(n=5\)（\(2^4 =16<30\)，\(2^5=32≥30\)）。  
3. 主机数需求：\(2^h -2 ≥50\) → \(2^h≥52\) → \(h=6\)（\(2^5 =32<52\)，\(2^6=64≥52\)）。  
4. 新网络位=16+5=21，验证：21+6=27≤32（合法）。  
5. 子网掩码：/21 → 二进制前21位为1，转换为十进制：255.255.248.0。  
答案：子网掩码为255.255.248.0（或/21）。


### 题型3：已知IP地址和子网掩码，求所属子网、广播地址、可用地址范围（必考题型）
#### 解题步骤：
1. 将IP地址和子网掩码转换为**二进制**（关键步骤，避免十进制误差）。  
2. 计算子网网络地址：IP地址二进制 & 子网掩码二进制（按位与），结果转换为十进制。  
3. 计算子网广播地址：子网网络地址的“主机位全改为1”，转换为十进制。  
4. 可用地址范围：子网网络地址+1 ~ 广播地址-1。  

#### 真题案例：
已知IP地址192.168.5.12，子网掩码255.255.255.240（/28），求所属子网、广播地址、可用地址范围。  
解：  
1. 二进制转换：  
   - IP地址：11000000.10101000.00000101.00001100  
   - 子网掩码：11111111.11111111.11111111.11110000（/28，主机位4位）  
2. 子网网络地址（按位与）：  
   11000000.10101000.00000101.00000000 → 192.168.5.0  
3. 广播地址（主机位全1）：  
   11000000.10101000.00000101.00001111 → 192.168.5.15  
4. 可用地址范围：192.168.5.1 ~ 192.168.5.14。  
答案：所属子网192.168.5.0/28，广播地址192.168.5.15，可用地址192.168.5.1~14。


### 题型4：定长子网划分（如将/24划分为多个子网，求每个子网的地址范围）
#### 解题步骤：
1. 确定原网络地址（如192.168.3.0/24）和新子网的网络位（如/26，即子网掩码255.255.255.192）。  
2. 计算子网块大小（步长）：步长 = \(256 - 子网掩码最后一个字节的十进制值\)（如256-192=64）。  
3. 依次列举每个子网的网络地址：从原网络地址开始，每次累加步长（如192.168.3.0、192.168.3.64、192.168.3.128、192.168.3.192）。  
4. 每个子网的广播地址 = 下一个子网的网络地址 - 1（如192.168.3.63、192.168.3.127等）。  
5. 可用地址范围 = 子网网络地址+1 ~ 广播地址-1。  

#### 真题案例：
将192.168.3.0/24划分为/26的子网，求所有子网的地址范围。  
解：  
1. 原网络/24，新网络/26 → 子网掩码255.255.255.192。  
2. 步长=256-192=64。  
3. 子网网络地址：0、64、128、192（共\(2^{26-24}=4\)个子网）。  
4. 各子网详情：  
   - 子网1：网络地址192.168.3.0，广播地址192.168.3.63，可用地址1~62。  
   - 子网2：网络地址192.168.3.64，广播地址192.168.3.127，可用地址65~126。  
   - 子网3：网络地址192.168.3.128，广播地址192.168.3.191，可用地址129~190。  
   - 子网4：网络地址192.168.3.192，广播地址192.168.3.255，可用地址193~254。  
   答案：4个子网，地址范围如上。


## 三、易错点提示（备考避坑）
1. 可用主机数必须减2（网络地址、广播地址不可分配），忘记减2直接错！  
2. 子网掩码转换时，最后一个字节计算：如/29对应主机位3位，子网掩码最后一个字节=256-8=248（而非255-3=252）。  
3. 按位与运算必须用二进制，十进制直接计算易出错（如IP=192.168.5.12，掩码=255.255.255.240，十进制12&240=0，而非12）。  
4. 定长子网划分的步长是“256-子网掩码最后一字节”，而非子网位的幂（如/26的步长是64，而非\(2^2=4\)）。  
5. VLSM（可变长子网掩码）需先满足主机数多的子网（分配更多主机位），再分配主机数少的子网，避免地址浪费。


## 四、总结（快速记忆口诀）
1. 子网数：\(2^n\)（n是新增子网位）；  
2. 主机数：\(2^h - 2\)（h是主机位）；  
3. 掩码转换：前k位1，后32-k位0（k是新网络位）；  
4. 子网地址：IP&掩码；广播地址：主机位全1；  
5. 步长计算：256减掩码最后一字节，地址范围首尾减1。
