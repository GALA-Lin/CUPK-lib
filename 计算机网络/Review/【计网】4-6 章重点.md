### 第一部分：PPT重点例题与核心概念总结

这部分涵盖了课件中涉及的关键计算、地址划分和协议流程。

#### **第4章：网络层**

1. **IP地址划分计算 (CIDR)**
   - **题目背景** ：一个单位获得了 $C$ 类网络地址 $192.168.1.0/24$，现在需要划分出 5 个子网。
   - **核心考点**：子网划分。
     - 需要 $N=5$ 个子网，则需要借用的主机位 $n$，满足 $2^n \ge N+2$（或 $2^n \ge N$，取决于是否允许全0全1的子网号）。若允许，则 $2^n \ge 5 \Rightarrow n=3$。
     - **子网掩码**：原 $/24$ 借 3 位 $\rightarrow /27$。即 $255.255 .255 .224$。
     - **每个子网主机数**：剩余主机位 $32-27=5$ 位。 $2^5-2 = 30$ 台主机（减去网络地址和广播地址）。
   - **例题分析** ：划分子网后，判断地址 $192.168.1.75$ 的子网地址、广播地址和主机地址。
     - $192.168.1.75$ 的二进制：`0100 1011`。
     - 子网掩码 `/27`：前 3 位为子网号，后 5 位为主机号。
     - **子网地址**：`010` (子网号) + `00000` (主机号) $\rightarrow 64$。即 $192.168.1.64$。
     - **广播地址**：`010` (子网号) + `11111` (主机号) $\rightarrow 95$。即 $192.168.1.95$。
2. **IP数据报首部格式**
   - **必考字段**：版本、首部长度（占4位，表示首部多少个4字节，最小为5，即20字节）、总长度、生存时间TTL（每经过一个路由器减1）、协议（指示上层协议，如6为TCP，17为UDP）、源地址、目的地址。

#### **第5章：运输层**

1. **TCP可靠传输（连续ARQ协议与滑动窗口）**
   - **题目背景** ：发送窗口大小 $W_T$。收到确认号 ACK=100，窗口大小 $W=300$。问发送方可以发送的最大序号是多少？
   - **核心考点**：
     - **发送窗口**：发送方允许发送但未收到确认的字节范围。
     - **发送窗口前沿**：已发送但未确认的最小序号。
     - **解析**：
       - 确认号 ACK=100 表示 100 号以前的字节均已收到确认，下一个应该收到的字节序号是 100。
       - 发送窗口前沿 = 100。
       - 窗口大小 $W=300$。
       - 发送窗口最大序号 = 窗口前沿 + 窗口大小 - 1 = $100 + 300 - 1 = 399$。
2. **TCP连接管理（三握手与四次挥手）**
   - **必考状态**：CLOSED, LISTEN, SYN-SENT, ESTABLISHED, FIN-WAIT-1, TIME-WAIT 。
   - **重点**：
     - **三握手**：目的是协商参数、同步序号和确认号，并分配缓存。
     - **四次挥手**：客户端（或服务器）发出 FIN 释放连接，对方回复 ACK，表示同意释放单向连接；当另一方也无数据发送时，再发出 FIN，对方回复 ACK，彻底释放连接。
     - **TIME-WAIT** 状态：客户端（主动关闭方）在收到最后一个 ACK 后，必须等待 2MSL（最长报文段生存时间）才进入 CLOSED 状态，目的是确保服务器收到最后一个 ACK。

#### **第6章：应用层**

1. **DNS域名解析流程**
   - **题目背景** ：主机访问 `www.xxx.com` 的域名解析过程。
   - **核心考点**：递归查询与迭代查询的结合。
     - 主机向**本地域名服务器**发起**递归查询**。
     - 本地域名服务器依次向**根域名服务器**、**顶级域名服务器** (`.com`)、**权限域名服务器** (`xxx.com`) 发起**迭代查询**。
     - 权限服务器返回最终 IP 地址给本地域名服务器，本地域名服务器将结果返回给主机，并缓存结果。
2. **HTTP报文结构与状态码**
   - **必考状态码**：200 OK（成功）、301 Moved Permanently（永久重定向）、302 Found（临时重定向）、404 Not Found（未找到）、500 Internal Server Error（服务器内部错误）。
   - **持久连接 vs 非持久连接**：持久连接中，一次 TCP 连接可以传输多个 HTTP 对象，减少了 TCP 握手的开销 。
3. **DHCP工作过程**
   - **口诀**：发现 (Discover) $\to$ 提供 (Offer) $\to$ 请求 (Request) $\to$ 确认 (ACK) 。

### 参考答案与解析

#### **一、单项选择题答案**

1. **B**
   - *解析*：A：IP是无连接的、不可靠的协议。C：ARP负责IP地址到MAC地址的映射。D：$224.0.0.1$ 是多播地址，不是广播地址。
2. **D**
   - *解析*：需要 $N=100$ 个子网。至少需要借用 $n$ 位主机位，满足 $2^n \ge 100$。$2^6=64$ 不够，$2^7=128$ 满足。
   - B类地址原网络位为 16 位，借 7 位后，网络位变为 $16+7=23$ 位。
   - 子网掩码为 $/23$，即 $255.255 .11111110 .0$ $\rightarrow 255.255 .254 .0$ **(错误)**。
   - 借 7 位，网络位是 $16+7=23$ 位。子网掩码是 $255.255.254.0$。
   - **重新计算：**
     - B类地址的网络号是前16位。子网号借用后16位中的 $n$ 位。
     - $n=7$ 位。网络号 $16+7=23$ 位。
     - 子网掩码为 23 个 1，即 $255.255 .254 .0$。选项 B 正确。
     - *更正*：选项 D $255.255 .252 .0$ 是 $/22$ (借 6 位，只能划分 $2^6=64$ 个子网，不满足 100 个)。故选 **B**。
3. **C**
   - *解析*：TIME-WAIT 状态等待 2MSL 的主要目的是确保发送方发送的最后一个 ACK 报文能够到达接收方，并让网络中所有该连接的报文段都消失，防止新的连接收到旧的报文。
4. **D**
   - *解析*：TCP (传输控制协议) 提供面向连接的可靠服务；UDP (用户数据报协议) 提供无连接的不可靠服务。
5. **B**
   - *解析*：发生**连续三次重复 ACK**（即快重传）时，表示网络并未出现严重拥塞，TCP 执行**快恢复**。它将慢开始门限 $ssthresh$ 减半，并将拥塞窗口 $cwnd$ 设置为 $ssthresh$，然后进入**拥塞避免**阶段（线性增长）。
6. **B**
   - *解析*：DNS (Domain Name System) 域名系统。
7. **B**
   - *解析*：发送邮件使用 **SMTP** (简单邮件传输协议，推协议)；接收邮件使用 **POP3** (邮局协议第三版，拉协议) 或 IMAP。

#### **二、计算与分析题答案**

1. 答案：

最短聚合地址为 $206.18 .168 .0 / 22$。

- **步骤 1：转二进制**
  - $168 \rightarrow 10101000$
  - $169 \rightarrow 10101001$
  - $170 \rightarrow 10101010$
- **步骤 2：找共同前缀**
  - $206.18.$ **$101010$** $00.0$
  - $206.18.$ **$101010$** $01.0$
  - $206.18.$ **$101010$** $10.0$
  - 第三个字节的共同前缀是前 6 位，即 $101010$。
- **步骤 3：计算聚合前缀长度**
  - 原网络前缀长度 $16$ 位 $+ 6$ 位共同前缀 $= 22$ 位。
- **步骤 4：确定聚合地址**
  - $206.18.$ **$101010$** $00.0 / 22$
  - 即 $206.18 .168 .0 / 22$。
  - *验证*：$/22$ 地址范围从 $206.18 .10101000 .0$ ($168.0$) 到 $206.18 .10101011 .255$ ($171.255$)，完整覆盖了 $168, 169, 170$ 三个网段。

 2.答案：

主机 A 当前可以发送的最大序号是 $9000$。

- 知识点：TCP 发送窗口范围定义：

  $ACK_{B} \le \text{发送序号} \le ACK_{B} + Win_{B} - 1$

- **确认号 $ACK=5001$**：表示 B 已成功收到序号到 5000 为止的所有字节。发送窗口的**前沿**是 5001。

- **窗口字段值 $Win=4000$**：表示 B 当前还能接收 4000 字节的数据。

- 发送窗口最大序号 = 窗口前沿 + 窗口大小 - 1

  $$= 5001 + 4000 - 1 = 9000$$

- **结论**：A 可以发送的序号范围是 $[5001, 9000]$。

 3.答案：

DNS 迭代查询完整步骤：

1. **Client $\to$ L-DNS (递归查询)**：Client 向本地域名服务器 (L-DNS) 发送查询请求：`www.lab.university.edu.cn` 的 IP 地址。
2. **L-DNS $\to$ 根域名服务器 (迭代查询)**：L-DNS 首先向根域名服务器查询。根服务器返回顶级域名服务器 `.cn` 的 IP 地址。
3. **L-DNS $\to$ 顶级域名服务器 (迭代查询)**：L-DNS 向 `.cn` 域名服务器查询。`.cn` 服务器返回下一级权威服务器 `.edu.cn` 的 IP 地址。
4. **L-DNS $\to$ 权威域名服务器 (迭代查询)**：L-DNS 向 `.edu.cn` 域名服务器查询。`.edu.cn` 服务器返回下一级权限域名服务器 `university.edu.cn` 的 IP 地址。
5. **L-DNS $\to$ 权限域名服务器 (迭代查询)**：L-DNS 向 `university.edu.cn` 的权限服务器查询。权限服务器最终返回 `www.lab.university.edu.cn` 对应的 IP 地址。
6. **L-DNS $\to$ Client (返回结果)**：L-DNS 将查到的 IP 地址返回给 Client，同时将该映射关系**缓存**起来。
7. **Client**：Client 得到 IP 地址，继续通过 HTTP 协议访问该网站。
