# CIDR 计算专项练习题及详细解析
## 核心结论
以下练习题覆盖 [[【计网】第4章 网络层]]CIDR 三大核心考点：**地址块范围计算、路由聚合（超网）、最长前缀匹配**，解析步骤清晰，结合二进制运算与实战逻辑，帮你彻底掌握 CIDR 计算技巧，适配期末考核与实际应用场景。

## 一、基础题型：CIDR 地址块范围计算（必考）
### 题型说明
已知 CIDR 地址（如 `192.168.1.0/24`），求子网掩码、网络地址、广播地址、地址总数、可用地址范围。  
核心公式：
- 子网掩码：前 n 位为 1，后（32-n）位为 0（n 为前缀长度）
- 网络地址 = IP 地址 & 子网掩码（按位与运算）
- 广播地址：网络地址的主机位（32-n 位）全置 1
- 地址总数 = 2^(32-n)
- 可用地址范围：网络地址 +1 ~ 广播地址 -1（排除全 0 网络地址和全 1 广播地址）

### 练习题 1
**题干**：已知 CIDR 地址 `172.16.3.0/22`，计算其子网掩码、网络地址、广播地址、地址总数及可用地址范围。

#### 解析步骤
1. **子网掩码推导**：前缀长度 22 → 前 22 位为 1，后 10 位为 0  
   二进制：`11111111.11111111.11111100.00000000` → 点分十进制：`255.255.252.0`
2. **网络地址计算**：IP 地址 `172.16.3.0` 与子网掩码 `255.255.252.0` 按位与  
   - 172.16.3.0 二进制：`10101100.00010000.00000011.00000000`  
   - 与子网掩码按位与后：`10101100.00010000.00000000.00000000` → 点分十进制：`172.16.0.0`
3. **广播地址计算**：网络地址主机位（后 10 位）全置 1  
   二进制：`10101100.00010000.00000011.11111111` → 点分十进制：`172.16.3.255`
4. **地址总数**：2^(32-22) = 1024 个
5. **可用地址范围**：`172.16.0.1 ~ 172.16.3.254`（排除网络地址 `172.16.0.0` 和广播地址 `172.16.3.255`）

#### 答案
- 子网掩码：`255.255.252.0`
- 网络地址：`172.16.0.0`
- 广播地址：`172.16.3.255`
- 地址总数：1024 个
- 可用地址范围：`172.16.0.1 ~ 172.16.3.254`

### 练习题 2
**题干**：已知 CIDR 地址 `10.20.15.8/29`，计算上述所有参数。

#### 解析步骤
1. **子网掩码**：前缀 29 → 前 29 位为 1 → 二进制 `11111111.11111111.11111111.11111000` → `255.255.255.248`
2. **网络地址**：`10.20.15.8 & 255.255.255.248` → 二进制 `00001010.00010100.00001111.00001000` → `10.20.15.8`
3. **广播地址**：主机位（后 3 位）全 1 → `10.20.15.15`
4. **地址总数**：2^(32-29) = 8 个
5. **可用地址范围**：`10.20.15.9 ~ 10.20.15.14`

#### 答案
- 子网掩码：`255.255.255.248`
- 网络地址：`10.20.15.8`
- 广播地址：`10.20.15.15`
- 地址总数：8 个
- 可用地址范围：`10.20.15.9 ~ 10.20.15.14`

## 二、进阶题型：路由聚合（超网）计算（高频考点）
### 题型说明
将多个连续的 CIDR 地址块聚合为一个更大的 CIDR 地址块，核心是找到所有地址的**最长共同网络前缀**，前缀长度 = 共同前缀位数。

### 练习题 3
**题干**：将 C 类地址块 `192.168.10.0/24`、`192.168.11.0/24`、`192.168.12.0/24`、`192.168.13.0/24` 聚合为一个 CIDR 地址块，求聚合后的网络地址和子网掩码。

#### 解析步骤
1. **转换为二进制**：提取前 24 位中的网络前缀部分（C 类地址默认前 24 位为网络位）
   - 192.168.10.0：`11000000.10101000.00001010.00000000`
   - 192.168.11.0：`11000000.10101000.00001011.00000000`
   - 192.168.12.0：`11000000.10101000.00001100.00000000`
   - 192.168.13.0：`11000000.10101000.00001101.00000000`
2. **找最长共同前缀**：对比前 22 位完全相同（前 21 位为 `11000000.10101000.000010`，第 22 位为 `00` 或 `01`？不，重新对比：
   前 22 位：`11000000.10101000.000010`（前 22 位），后 10 位为主机位 → 共同前缀长度为 22
3. **聚合后网络地址**：共同前缀 + 主机位全 0 → `11000000.10101000.00001000.00000000` → `192.168.8.0`
4. **子网掩码**：前缀 22 → `255.255.252.0`

#### 答案
- 聚合后网络地址：`192.168.8.0/22`
- 子网掩码：`255.255.252.0`

### 练习题 4
**题干**：聚合地址块 `202.118.64.0/23`、`202.118.66.0/23`、`202.118.68.0/23`，求聚合后的 CIDR 地址。

#### 解析步骤
1. **转换为二进制**（前 23 位为网络位）
   - 202.118.64.0：`11001010.01110110.01000000.00000000`
   - 202.118.66.0：`11001010.01110110.01000010.00000000`
   - 202.118.68.0：`11001010.01110110.01000100.00000000`
2. **找共同前缀**：前 21 位相同（`11001010.01110110.010`），第 22-23 位不同 → 共同前缀长度 21
3. **聚合后网络地址**：`11001010.01110110.01000000.00000000` → `202.118.64.0/21`

#### 答案
聚合后 CIDR 地址：`202.118.64.0/21`（子网掩码 `255.255.248.0`）

## 三、实战题型：最长前缀匹配（路由转发核心）
### 题型说明
已知路由表中的 CIDR 路由条目，给定目的 IP 地址，选择前缀最长的匹配路由（前缀越长，地址块越精确，优先级越高）。

### 练习题 5
**题干**：路由表中有以下条目：
1. `202.118.0.0/18` → 接口 1
2. `202.118.68.0/22` → 接口 2
3. `202.118.69.0/24` → 接口 3
目的 IP 地址为 `202.118.69.150`，求转发接口。

#### 解析步骤
1. **逐个匹配路由条目**：
   - 条目 1（/18）：前缀 18 位 → 网络地址 `202.118.0.0`，覆盖范围 `202.118.0.0 ~ 202.118.63.255`？不，/18 子网掩码 `255.255.192.0`，覆盖 `202.118.0.0 ~ 202.118.63.255`？不对，重新计算：`202.118.0.0/18` 主机位 14 位，范围 `202.118.0.0 ~ 202.118.63.255` → 目的 IP 202.118.69.150 不匹配。
   - 条目 2（/22）：子网掩码 `255.255.252.0`，网络地址 `202.118.68.0`，覆盖范围 `202.118.68.0 ~ 202.118.71.255` → 目的 IP 在此范围内，匹配。
   - 条目 3（/24）：子网掩码 `255.255.255.0`，网络地址 `202.118.69.0`，覆盖范围 `202.118.69.0 ~ 202.118.69.255` → 目的 IP 在此范围内，匹配。
2. **比较前缀长度**：条目 3（/24）> 条目 2（/22）→ 选择最长前缀的条目 3。

#### 答案
转发接口：接口 3

### 练习题 6
**题干**：路由表条目：
1. `10.0.0.0/8` → 网关 A
2. `10.1.0.0/16` → 网关 B
3. `10.1.2.0/24` → 网关 C
4. `10.1.2.32/27` → 网关 D
目的 IP：`10.1.2.45`，求转发网关。

#### 解析步骤
1. **匹配验证**：
   - 条目 4（/27）：网络地址 `10.1.2.32`，覆盖 `10.1.2.32 ~ 10.1.2.63` → 目的 IP 45 在此范围，匹配。
   - 其他条目均匹配，但前缀长度 /27 最长。
2. **结论**：选择网关 D。

#### 答案
转发网关：网关 D

## 四、易错点总结
1. 计算网络地址时，必须将 IP 地址和子网掩码转为二进制进行按位与，避免十进制直接计算出错。
2. 路由聚合时，需确保所有地址块连续，且共同前缀是“最长”的（不是任意共同前缀）。
3. 最长前缀匹配时，先验证目的 IP 是否在路由覆盖范围，再比较前缀长度，不可直接按前缀长度排序后跳过匹配验证。
