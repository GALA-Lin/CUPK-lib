# 争用期计算专题（CSMA/CD核心考点+期末真题级练习）
## 核心结论
争用期（又称碰撞窗口）是[[【计网】第3章 数据链路层#6. 介质访问控制协议 CSMA/CD [考试重点：原理与计算]]]以太网CSMA/CD协议的核心参数，定义为“端到端传播时延的2倍”（`争用期=2×tₚ`，`tₚ`为信号从一端传到另一端的传播时延），目的是确保发送方在发送数据后能检测到所有可能的碰撞。**其计算核心是“传播时延×2”，需牢记信号传播速率（双绞线/光纤常用值）和不同速率以太网的争用期标准值**，是期末计算题高频考点。

## 一、核心概念与计算公式
### 1. 争用期的本质
- 以太网中，发送方发送数据后，需在“争用期”内检测是否发生碰撞：若未检测到碰撞，则后续数据不会再碰撞；若检测到碰撞，立即停止发送并退避。
- 核心逻辑：信号从A传到B的时间为`tₚ`，若B在`tₚ`内发送数据，碰撞信号需再经`tₚ`传回A，因此A需等待`2tₚ`才能确认无碰撞。

### 2. 关键公式
- 传播时延：`tₚ = 信道长度(L) / 信号传播速率(v)`  
  （双绞线/光纤中信号传播速率≈`2×10⁸m/s`，光速的2/3，期末默认此值，除非题目明确给出其他值）
- 争用期：`T = 2×tₚ = 2L / v`
- 衍生公式（最短帧长）：`最短帧长 = 发送速率(R) × 争用期(T)`  
  （以太网通过最短帧长确保争用期内可检测碰撞，如10Mb/s以太网最短帧长64字节=10Mb/s×51.2μs）

### 3. 以太网标准争用期参数（期末必记）
| 以太网速率 | 争用期标准值 | 对应最短帧长 | 信号传播速率 |
| ---------- | ------------ | ------------ | ------------ |
| 10Mb/s     | 51.2μs       | 64字节       | 2×10⁸m/s     |
| 100Mb/s    | 5.12μs       | 64字节       | 2×10⁸m/s     |
| 1Gb/s      | 0.512μs      | 64字节       | 2×10⁸m/s     |

## 二、典型场景计算（期末高频）
### 场景1：已知信道长度，计算争用期
#### 例题1
**题干**：某10Mb/s以太网使用双绞线连接，两主机间距100m，信号传播速率`2×10⁸m/s`，求争用期。
#### 解析
1. 计算传播时延：`tₚ = 100m / (2×10⁸m/s) = 5×10⁻⁷s = 0.5μs`
2. 争用期：`T = 2×0.5μs = 1μs`
#### 答案：1μs

### 场景2：已知争用期，反推信道最大长度
#### 例题2
**题干**：某100Mb/s以太网要求争用期≤5.12μs，信号传播速率`2×10⁸m/s`，求两主机的最大允许间距。
#### 解析
1. 由`T=2L/v`变形得：`L = (T×v)/2`
2. 代入数值：`L = (5.12×10⁻⁶s × 2×10⁸m/s)/2 = 512m`
#### 答案：512m

### 场景3：结合最短帧长的争用期验证
#### 例题3
**题干**：某千兆以太网（1Gb/s）的最短帧长为64字节，验证其争用期是否符合标准值（`0.512μs`）。
#### 解析
1. 最短帧长转换为比特：`64字节×8=512bit`
2. 由`最短帧长=R×T`变形得：`T = 最短帧长/R`
3. 代入数值：`T = 512bit / (1×10⁹bit/s) = 5.12×10⁻⁷s = 0.512μs`，与标准值一致。
#### 答案：验证成立，争用期为0.512μs

## 三、易错点总结（避坑关键）
1. 信号传播速率取值错误：双绞线/光纤中默认`2×10⁸m/s`，而非光速（`3×10⁸m/s`），题目未说明时按此取值。
2. 忘记“×2”：争用期是2倍传播时延，直接用传播时延作为争用期是最常见错误。
3. 单位换算错误：需统一单位（如m→m，s→μs，1μs=10⁻⁶s），例：`5×10⁻⁷s=0.5μs`，而非500μs。
4. 混淆速率与争用期关系：以太网速率越高，争用期越短（如10Mb/s→51.2μs，100Mb/s→5.12μs），但最短帧长保持64字节不变。

## 四、期末真题级练习题（含解析）
### 练习题1（基础题）
**题干**：某校园网使用光纤连接两栋楼，距离500m，信号传播速率`2×10⁸m/s`，该网段为100Mb/s以太网，求争用期和最短帧长。
#### 解析
1. 传播时延：`tₚ=500m/(2×10⁸m/s)=2.5μs`
2. 争用期：`T=2×2.5μs=5μs`（接近100Mb/s标准争用期5.12μs，因实际信道损耗可忽略）
3. 最短帧长：`100×10⁶bit/s ×5×10⁻⁶s=500bit=62.5字节`（实际取64字节，满足标准）
#### 答案：争用期5μs，最短帧长64字节

### 练习题2（进阶题）
**题干**：某10Mb/s以太网中，两主机间距2km，信号传播速率`2×10⁸m/s`，若发送方发送一个32字节的帧，是否能检测到碰撞？为什么？
#### 解析
1. 计算争用期：`T=2×(2000m/(2×10⁸m/s))=20μs`
2. 计算32字节帧的发送时延：`tₜ=（32×8bit）/(10×10⁶bit/s)=25.6μs`
3. 关键判断：发送时延（25.6μs）>争用期（20μs），发送方在争用期内已发送完帧，无法检测到碰撞。
#### 答案：不能检测到碰撞；原因是32字节帧的发送时延（25.6μs）大于争用期（20μs），发送方已发送完帧，无法检测后续碰撞。

### 练习题3（综合题）
**题干**：某以太网争用期为10μs，信号传播速率`2×10⁸m/s`，求：（1）信道长度；（2）若该网络升级为1Gb/s，保持信道长度不变，新的争用期是多少？（3）升级后最短帧长需调整为多少？
#### 解析
1. 信道长度：`L=(T×v)/2=(10×10⁻⁶s×2×10⁸m/s)/2=1000m`
2. 升级后争用期：`T'=2×(1000m/(2×10⁸m/s))=10μs`（信道长度不变，争用期不变）
3. 升级后最短帧长：`1×10⁹bit/s ×10×10⁻⁶s=10⁴bit=1250字节`
#### 答案：（1）1000m；（2）10μs；（3）1250字节

# 争用期+最短帧长综合计算压轴题（期末难度+超详细解析）

## 核心说明
以下2道压轴题综合考查争用期、最短帧长、发送时延、碰撞检测判断、网络升级适配等核心知识点，融合多步计算与实际场景分析，完全贴合期末压轴题的命题逻辑，解析标注关键公式与易错点，帮你吃透这类综合题型。

## 压轴题1（多问综合+碰撞检测+帧长调整）
### 题干
某企业园区网采用100Mb/s以太网（CSMA/CD协议），核心交换机与远端办公楼主机的光纤链路长度为800m，信号在光纤中的传播速率为`2×10⁸m/s`，忽略处理时延和排队时延。请回答以下问题：
1. 计算该链路的争用期（碰撞窗口）；
2. 计算该以太网的最短帧长（以字节为单位）；
3. 若某主机发送一个40字节的UDP数据报（含IP首部20字节、UDP首部8字节），该数据报封装成以太网帧后（以太网帧首部18字节、FCS 4字节），发送方能否检测到链路上的碰撞？请通过计算说明；
4. 若该链路因施工延长至1500m，为保证碰撞检测有效，最短帧长需调整为多少字节？若保持原最短帧长不变，可采取什么措施？

### 解析步骤
#### 1. 计算争用期
- 核心公式：争用期 `T = 2×tₚ`，其中传播时延 `tₚ = 信道长度(L) / 信号传播速率(v)`
- 代入数据：`tₚ = 800m / (2×10⁸m/s) = 4×10⁻⁶s = 4μs`
- 争用期：`T = 2×4μs = 8μs`
- 易错点：忘记“×2”，直接将传播时延当作争用期，导致结果减半。

#### 2. 计算最短帧长
- 核心公式：最短帧长 `L_min = 发送速率(R) × 争用期(T)`
- 单位换算：100Mb/s = 100×10⁶bit/s，T=8×10⁻⁶s
- 计算：`L_min = 100×10⁶bit/s × 8×10⁻⁶s = 800bit`
- 转换为字节：`800bit ÷ 8 = 100字节`
- 说明：100Mb/s以太网标准最短帧长为64字节，但本题因链路更长，争用期增大，需自定义最短帧长以保证碰撞检测。

#### 3. 判断40字节UDP数据报封装后的碰撞检测能力
- 第一步：计算以太网帧总长度
  以太网帧 = 以太网首部（18字节）+ IP数据报（20+8+40=68字节）+ FCS（4字节）= 18+68+4=90字节
- 第二步：计算该帧的发送时延
  发送时延 `t_tx = 帧长度 × 8bit/字节 ÷ 发送速率`
  代入数据：`t_tx = 90×8bit ÷ (100×10⁶bit/s) = 720bit ÷ 10⁷bit/s = 7.2×10⁻⁶s = 7.2μs`
- 第三步：碰撞检测判断规则
  若发送时延 `t_tx ≤ 争用期T`，发送方可在发送过程中检测到碰撞；若 `t_tx > T`，发送方已发送完帧，无法检测碰撞
  本题中：7.2μs < 8μs → 发送方可检测到碰撞

#### 4. 链路延长后的最短帧长调整与措施
- （1）计算延长后的争用期
  新信道长度L'=1500m，`tₚ' = 1500m / (2×10⁸m/s) = 7.5μs`
  新争用期 `T' = 2×7.5μs = 15μs`
  新最短帧长 `L_min' = 100×10⁶bit/s × 15×10⁻⁶s = 1500bit = 187.5字节 → 向上取整为188字节`（帧长需为整数字节）
- （2）保持原最短帧长（100字节）的措施
  核心逻辑：缩短争用期或增大发送速率
  可行措施：将以太网速率升级为1Gb/s（发送速率提升，最短帧长可保持不变），或在链路中间增加中继器（缩短有效传播距离，减小争用期）

### 答案
1. 争用期：8μs；
2. 最短帧长：100字节；
3. 能检测到碰撞；理由：封装后的以太网帧长90字节，发送时延7.2μs < 争用期8μs，发送方可在发送过程中检测碰撞；
4. 链路延长后最短帧长需调整为188字节；保持原最短帧长的措施：升级以太网速率为1Gb/s，或在链路中间增加中继器。

## 压轴题2（网络升级+多主机间距+退避时间+最短帧长适配）
### 题干
某校园网原采用10Mb/s以太网，连接图书馆与教学楼的双绞线链路长度为300m，信号传播速率`2×10⁸m/s`。现因业务需求，将网络升级为1Gb/s以太网，链路长度不变。请回答以下问题：
1. 计算原10Mb/s以太网的争用期和最短帧长；
2. 计算升级后1Gb/s以太网的争用期和最短帧长；
3. 若图书馆有两台主机A、B，与教学楼主机C的间距分别为300m和500m（均通过该链路连接，信号传播速率不变），求主机A与C、主机B与C通信时的争用期分别为多少？
4. 主机A发送数据时检测到碰撞，执行二进制指数退避算法，第1次重传选择随机数r=3，第2次重传选择r=5，分别计算两次重传的等待时间（以μs为单位）；
5. 升级后，若某应用发送的帧长为512字节，该帧的发送时延是否大于争用期？是否能保证碰撞检测有效？

### 解析步骤
#### 1. 原10Mb/s以太网的争用期和最短帧长
- 争用期计算：`tₚ = 300m / (2×10⁸m/s) = 1.5μs`，`T = 2×1.5μs = 3μs`
- 最短帧长：`L_min = 10×10⁶bit/s × 3×10⁻⁶s = 30bit = 3.75字节 → 按以太网标准取64字节`（实际以太网最短帧长为64字节，确保兼容性）

#### 2. 升级后1Gb/s以太网的争用期和最短帧长
- 争用期：链路长度不变，传播速率不变 → 争用期仍为3μs（争用期与发送速率无关，仅与链路长度和传播速率相关）
- 最短帧长：`L_min' = 1×10⁹bit/s × 3×10⁻⁶s = 3000bit = 375字节`
- 易错点：误以为发送速率提升会改变争用期，实际争用期仅由链路物理特性决定。

#### 3. 不同主机间距的争用期计算
- 核心逻辑：争用期=2×（主机间距/传播速率）
- 主机A与C（300m）：`T_A-C = 2×(300m/(2×10⁸m/s)) = 3μs`
- 主机B与C（500m）：`T_B-C = 2×(500m/(2×10⁸m/s)) = 5μs`
- 结论：争用期随主机间距增大而增大，需按最大间距设计最短帧长。

#### 4. 二进制指数退避等待时间计算
- 核心规则：退避时间 = r × 争用期（升级后争用期为3μs，按当前网络争用期计算）
- 第1次重传：r=3，等待时间 = 3×3μs = 9μs
- 第2次重传：重传次数k=2，k≤10，退避时间 = 5×3μs = 15μs
- 说明：二进制指数退避算法中，r的取值范围为[0,2ᵏ-1]，本题r值在合理范围内。

#### 5. 512字节帧的发送时延与碰撞检测有效性
- 发送时延计算：`t_tx = 512×8bit ÷ (1×10⁹bit/s) = 4096bit ÷ 10⁹bit/s = 4.096μs`
- 碰撞检测判断：发送时延4.096μs > 争用期3μs → 发送方已发送完帧，无法检测到碰撞？
- 修正：实际需按最大争用期（5μs，B与C的争用期）判断：4.096μs < 5μs → 能检测到碰撞（网络需按最大间距设计，确保所有主机通信时碰撞检测有效）

### 答案
1. 原10Mb/s以太网：争用期3μs，最短帧长64字节；
2. 升级后1Gb/s以太网：争用期3μs，最短帧长375字节；
3. 主机A与C争用期3μs，主机B与C争用期5μs；
4. 第1次重传等待时间9μs，第2次重传等待时间15μs；
5. 发送时延4.096μs；能保证碰撞检测有效；理由：按网络最大争用期5μs判断，发送时延4.096μs < 5μs，发送方可在发送过程中检测碰撞。

## 压轴题核心考点总结
1. 公式联动：争用期（物理特性）→ 最短帧长（与发送速率联动）→ 发送时延（与帧长、速率联动）→ 碰撞检测（发送时延≤争用期）；
2. 不变量判断：争用期与发送速率无关，仅由链路长度和传播速率决定；
3. 实际适配：最短帧长需取整数字节，且不小于以太网标准64字节（兼容现有设备）；
4. 单位换算：牢记1字节=8bit，1μs=10⁻⁶s，避免计算错误。
